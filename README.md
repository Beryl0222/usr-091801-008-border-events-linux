# 口岸文旅双语运营

本项目管理口岸城市的活动、接驳、商户与通关提示。中文事实源由责任单位维护，俄文内容由译员关联到具体中文版本；通关类内容还需政策复核，并使用口岸当地时区描述生效区间。

公开内容、承办方联系人和部门处置记录使用不同可见级别。活动样例包括体育大会、合唱交流、贸易博览会和夜间市集，变化事件覆盖取消、延期、容量调整、接驳变化与商户临时停业。

## 领域能力（`border_events/`）

- `content.py` — 中文事实源的提交、修订与发布；译稿锚定中文版本号形成中俄文追溯；通关类内容必须复核通过并带生效区间才可发布；紧急更正一次调用完成修订、加急复核、发布并同步清除缓存。
- `timeutil.py` — 所有时间必须携带时区偏移，内部统一 UTC，仅展示时换算口岸当地时区，支持运营人员跨时区录入。
- `stream.py` — 取消、改期、容量调整、接驳变化、商户停业等事件统一汇入并应用到内容。
- `favorites.py` — 游客收藏与跨日行程冲突检测，变更通知必附同口岸当日的替代方案。
- `analytics.py` — 浏览与到场转化只保存聚合计数，不记录游客标识，导出时抑制小单元格，不留可还原个人行程的轨迹。

## 关键约束

- 过期政策内容即使缓存节点仍持有，对外一律不返回（缓存条目带版本与有效截止，返回前再验证）。
- 政策类译稿落后于中文版本时不得对外提供；普通内容带 `stale` 标记并暴露源版本号。
- 可见范围：公开 < 承办方 < 内部处置，逐级收紧。

## 运行与验证

```bash
python3 service.py --check          # 基础自检
python3 service.py --port 8000      # 启动服务
curl 'http://127.0.0.1:8000/public/content/visa-notice?lang=ru'
npm test                            # 或 python3 -m unittest service_contract test_domain
```
